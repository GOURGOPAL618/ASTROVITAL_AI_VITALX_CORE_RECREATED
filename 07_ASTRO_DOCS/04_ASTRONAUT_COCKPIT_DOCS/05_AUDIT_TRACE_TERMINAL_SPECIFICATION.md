## 1. Functional Purpose & White-Box Explainability

The `audit_trace_terminal.py` component provides total, uncompromised explainability for every diagnostic alert generated by ASTROVITAL. In compliance with aerospace flight software certification, black-box decision making is strictly forbidden. The terminal outputs:
1. **ASCII CRT Monospace Flight Trace:** Real-time console logs showing pipeline transition steps:
   `RAW INTAKE` $\to$ `KALMAN FILTER` $\to$ `SANITY GATE` $\to$ `BIOPHYSICAL MODEL` $\to$ `RULE ID` $\to$ `HUD DISPATCH`.
2. **Mathematical Variable Inspection:** Step-by-step arithmetic values ($I_{\text{ICP}}$, $SV$, $SI$, $MAP$, $PP$, $\Delta t$).
3. **Cryptographic Provenance:** Dynamic SHA-256 digest calculation and execution latency ($ms$).
4. **Exportable JSON Telemetry Packet:** Formatted payload for mission control telemetry downlinks.
